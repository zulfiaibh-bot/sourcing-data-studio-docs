Data APIs for importers who buy from China and sell in the Gulf. Each API runs on the [Apify Store](https://apify.com/store), returns clean product and supplier rows, and charges only for results that are delivered.

## APIs in preparation

| API | What it returns | Status |
|---|---|---|
| Temu Product API | Product prices, discounts, ratings and sales signals for the US, UK, UAE and KSA storefronts | in testing |
| 1688 Image Search API | Suppliers for a product photo, with MOQ ladder, tier prices and supplier badges | planned |
| Landed cost and margin layer | Duty, VAT, freight band, marketplace fees and margin for Bahrain, UAE and Saudi Arabia | planned |

## How the APIs work

- Pay per result: failed pages, duplicates and incomplete rows are never charged.
- Use them from Apify Console, the Apify API, n8n, Make or AI agents through the Apify MCP server.
- Public listing data only: no logins, no personal data.

Links to each API's Store page will appear here when it is published.
